# Curve mode artwork

CURVE-ICONS-01: original 16 x 16 SVG mini-curves, exported as plain SVG through
Inkscape 1.4.4. Covered by the project license. No upstream SVGs are bundled.

Polynomial and analytic silhouettes use fixed representative curves. Bounce,
Elastic, Spring and Physics Spring use OUT-style silhouettes; Smoothstep uses
canonical IN_OUT. Discrete and CSS icons use fixed authored knots. These are
identifiers, not live previews of the selected resource or its parameters.

The Inspector prefers Godot's CurveConstant, CurveLinear, CurveInOut and four
ease-mode icons. Standalone callers use these SVG fallbacks. Custom Editor
variants darken for light themes and scale once, with cached textures.
